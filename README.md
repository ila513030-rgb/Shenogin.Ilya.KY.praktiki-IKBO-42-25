## Этап 1. REPL

Консольный эмулятор с приглашением `username@hostname:~$`,
основанным на реальных данных операционной системы.

Парсер поддерживает переменные окружения, например `$HOME`.
Команды `ls` и `cd` пока являются заглушками: выводят аргументы.
Команда `exit` завершает диалог. Неизвестные команды и ошибочные
аргументы обрабатываются сообщением об ошибке.

### Запуск

Linux: `sh run.sh`  
Windows: `run.bat`

Пример:

```text
user@host:~$ ls $HOME
ls: аргументы = ['/home/user']
user@host:~$ cd docs
cd: аргументы = ['docs']
user@host:~$ wrong
Ошибка: неизвестная команда wrong
user@host:~$ exit
```
